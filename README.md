# Student Grade Analyzer

## About the Project

The **Student Grade Analyzer** is a beginner-friendly Python project that collects students' names and scores in three subjects, calculates their average scores, assigns grades, and displays a report for all recorded students.

This project was built to practice fundamental Python programming concepts through a practical, real-world application.

## Features

- Collects student names.
- Accepts scores for three subjects per student.
- Calculates each student's average score.
- Assigns grades from A to F based on the average.
- Allows users to record multiple students.
- Stores student records using Python lists and dictionaries.
- Displays a final report containing each student's name, scores, average, and grade.

## Grading System

| Average Score | Grade |
| ------------- | ----- |
| 70 and above  | A     |
| 60–69.99      | B     |
| 50–59.99      | C     |
| 45–49.99      | D     |
| 40–44.99      | E     |
| Below 40      | F     |

*Note: This grading scale is used for this practice project and may differ from the grading system of an actual institution.*

## How to Run the Project

1. Install Python 3 on your computer if you haven't already.

2. Download or clone this repository.

3. Open the project folder in your code editor or terminal.

4. Run the Python file:

   ```bash
   python student_grade_analyzer.py
   ```

   Replace `student_grade_analyzer.py` with the actual name of your Python file if it differs.

5. Follow the prompts to enter student names and scores.

6. Choose whether to record another student.

7. View the final student report.
